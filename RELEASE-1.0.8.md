# TM Last Epoch Co-op Mod 1.0.8 / protocol 21

Development build addressing the reported reward crash, long-map enemy limit, Gift stats, crowd control, presentation and party health scaling. Both PCs must update Mod and Core. Customized LE HUD remains 1.0.0.

- Long-map history no longer treats 512 cumulative kills as a fatal limit. Retain at most 128 recent corpse snapshots, ordered by death time, while keeping terminal identities separate so stale samples cannot resurrect old enemies. Remove dead Actors from the host sampling loop. The wire still allows at most 512 simultaneous records; an overfull live set is bounded with bosses first rather than disconnecting the room. A burst that fills that whole budget can still lose a reward transition.
- Assign a fresh replica's DeathItemDrop.dying reference before native death/callback dispatch. A partially completed native reward exception is consumed and logged once without disconnecting the room or retrying potentially duplicated loot. This does not guarantee every native reward callback succeeds.
- Gift sends rebuilt serialization and receives ItemDataUnpacked, preserving the native implicit/affix cache used by gameplay and tooltips. Native synthetic-item QA verifies byte identity, implicit rolls/data and affix ID/tier/roll after decoding. It does not repair previously delivered items or cover every unique/legendary/memory variant.
- Guest stun/freeze/time-lock/petrify requests use the authenticated, range- and epoch-checked hit-command transport. Host invokes the original native methods with normal immunity checks. Authoritative freeze/stun state uses native ActorSync VFX receivers on Guest. Full ailment/on-hit/leech semantics remain incomplete.
- Replicate visual positions separately from gameplay poses and interpolate them on the same presentation clock. This preserves host visual displacement, including some emergence/landing motion previously flattened to gameplay position. Not every scripted aerial event is covered.
- Native controller parameter capture prioritizes movement/combat inputs before the bounded budget and ignores invalid native values instead of losing the whole snapshot. Native asset fixture verifies movement/attack drivers for all five classes. The isolation fixture now explicitly allows the same animation loader and disabled equipment joints already retained by production models; it continues rejecting gameplay scripts/colliders/active drivers.
- Host overrides the native GroupScalingManager with party count in the same map and uses its level/type health curve. Restore the previous override on disconnect. Actual campaign HP values after party joins/leaves require testing.
- Forward equipped aura/footprint prefab GUIDs and render them on remote models. Footprints use a bounded, reused pool and local distance-based step cadence. Rendering-only isolation can omit custom prefab scripts; all cosmetic variants are not verified.
- Guest interactions with recognized, locally placed shrines request Host validation. Host journal carries the shrine ability key; matching Guest shrines replay the host ability on the local player. This relies on matching paths or a nearby local shrine, not authoritative procedural shrine placement. It does not guarantee correct duration for late joiners or shrine variants without CastAtPointInteraction.
- Add Nemesis click/corpse/rift objects to the existing native object-state replication. Nemesis encounter choices, empower/banish, item containers and full progression are still not synchronized.

Verification: clean Release build; 198 managed checks including 2,000 kills in one instance, old-spawn boss death retention, authenticated freeze transport and cosmetic identity wire/copy. Private native asset QA passes item-stat round trip, five class models/movement/attack drivers and the existing adapter/health/ownership gates. No real two-PC campaign encounter, shrine/Nemesis operation, party scaling measurement or FPS benchmark is available for this build.

Distribution: original Mods/LastEpochLAN.dll, Mods/LastEpoch_Hud.dll and UserLibs/LastEpochLAN.Core.dll, without ZIP/Installer. Use Update-And-Launch.cmd on both PCs after closing the games.
